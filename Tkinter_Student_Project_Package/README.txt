SMART STUDENT TASK & DEADLINE TRACKER
======================================

FILES
- smart_task_tracker.py : runnable Tkinter application
- Tkinter_Project_Report.docx : editable project report
- Tkinter_Project_Presentation.pptx : editable PPT for printing
- VIVA_AND_DEMO_GUIDE.txt : setup, demo sequence and viva preparation

RUN
1. Install Python 3 from python.org if it is not already installed.
2. Keep smart_task_tracker.py in a folder.
3. Open Command Prompt / Terminal in that folder.
4. Run: python smart_task_tracker.py
   If needed: python3 smart_task_tracker.py
5. A window opens. Add a task. The file tasks.csv is created automatically
   when you add the first valid task.

SAMPLE DEMO DATA
Task title: Complete DSA Assignment
Subject: DSA
Deadline: 2026-11-20
Priority: High

DEMONSTRATION ORDER
1. Explain the problem and project purpose.
2. Add the sample task.
3. Show it in the table and point out the Pending status.
4. Mark it Completed.
5. Change filter to Completed and then Pending.
6. Add another task and delete it.
7. Close and reopen the program to prove CSV persistence.
8. Explain the validation by entering an invalid date (e.g. 20-11-2026).

IMPORTANT
- The deadline must use YYYY-MM-DD format.
- Tkinter is included with most standard Python installations.
- On some Linux systems, Tkinter may need installation through the OS package manager.
- Do not claim to have tested a feature unless you run it yourself on your computer.
